ALGORITHM NOTES

Meet Depth First Search.

A simple strategy with a very particular way of exploring.

Assigned · Algorithm 2
THE CORE IDEA

Go deeper.
Then backtrack.

DFS follows one branch of the search tree as far as it can. When it reaches a dead end, it returns to the most recent state with unexplored options.

S
ABC
…D…
DFS follows the highlighted branch first
↘

Working principle

  1. Put the initial state on a stack.
  2. Pop the most recently added state.
  3. If it is the goal, stop.
  4. Otherwise generate valid successor states.
  5. Add unvisited successors to the stack and continue.
＋

Advantages

  • Often uses less memory than breadth-first search.
  • Can find a solution without exploring every shallow state first.
  • Simple to implement using a stack or recursion.
!

Limitations

  • May follow a long, unhelpful branch.
  • Does not guarantee the shortest path.
  • Without cycle checks or limits, it can revisit states or search deeply.
ƒ

Complexity & properties

PSEUDOCODE

DFS in five lines

frontier ← stack containing initial state
explored ← empty set
while frontier is not empty:
    state ← pop(frontier)
    if state is goal: return solution path
    if state not in explored: add state and push unvisited successors
return failure
